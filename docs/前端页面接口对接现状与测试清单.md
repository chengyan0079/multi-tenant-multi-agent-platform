# 前端页面接口对接现状与测试清单

> 用途：按「前端有 UI + 后端有接口 + 端到端能跑通」三条件核对每个功能到底完成没有，供测试与排期使用。
> 代码基线：前端 `dashboard/src`，后端 `backend/api/v1`。

## 1. 完成判定标准

一项功能算「对接完成」必须同时满足三条，缺任意一条都记未完成：

| 条件 | 含义 |
| --- | --- |
| 后端接口已实现 | 路由存在、能返回正确数据、走统一 `{code,msg,data}` 信封 |
| 前端有入口并调真实接口 | 页面上有对应按钮/表单，Network 里能看到请求，不是 mock 数据 |
| 端到端验证过 | 真实点过一遍，成功路径与失败路径都有预期表现 |

判定结果只写事实，不写「大概能用」。因此下面分两种粒度：
**页面级**（这个页面整体算不算完成）和**功能点级**（具体哪一件事缺哪一侧）。

## 7. 页面测试要点

### 7.1 登录 `/login`

- 正常：提示「欢迎回来，xxx」→ 跳 `/dashboard`
- 密码错误：`401 + code=40100`，红色提示、不跳转
- 后端未启动：「网络异常，请确认后端服务已启动」
- 已登录访问 `/login` → 自动跳 `/dashboard`

### 7.2 监控概览 `/dashboard`

- 切 7/30 天重新请求；指标卡、趋势、占比、时段耗时、最近活动、租户用量排行（仅超管）取接口数据
- 接口失败：黄色 Alert + 退示例数据并打橙色「示例数据」标签（看到此标签说明接口没通）

### 7.3 智能体管理 `/agents`

- 列表含 `registered`（已注册 / 仅库登记）；开关调 `PATCH .../enabled`
- 没有详情入口，没有租户开通策略入口（未完成项）

### 7.4 工具与插件 `/tools`

- 只展示 `GET /admin/plugins` 返回的能力名；页头有说明条
- 没有启停、没有调用次数（后端也没有）
- 当前插件注册表为空 → 空表属正常

### 7.5 模型注册表 `/models`

- 列表可按类型筛选；启用开关直接调 `PUT`，其它字段沿用该行原值
- **api_key**：后端脱敏返回 `***`，编辑弹窗留空表示保留原 key，前端不会把 `***` 写回
- 平台级资源，不分租户；改动即时影响运行时取模型

### 7.6 用户管理 `/users`

- 列表支持用户名、租户、创建时间筛选；详情抽屉改角色（`student / teacher / tenant_admin` 等，均不预置，由超管创建）
- 加载失败显示红色 Alert + 重试
- 无新建用户入口（后端也没有超管建用户接口）

### 7.7 租户管理 `/tenants`

- 列表支持名称、创建时间筛选；「新建租户」只填名称，新建的**恒为主租户**（全局唯一，已存在则报错）
- 抽屉：改名/启停（主租户启用开关禁用）、换管理员（新用户必须填密码）
- 无删除入口（后端也没有）

### 7.8 角色管理 `/roles`

- 详情抽屉的权限点是**覆盖保存**：勾选结果即全部权限点，取消勾选会删除
- 权限点选项来自前端常量 `SCOPE_OPTIONS`，与后端 `Scope` 枚举对齐，非法值后端直接拒
- 内置角色（`1/2/3/5`，前端写死）不显示删除按钮；删除无二次确认
- 改内置角色权限会影响线上鉴权，测试用临时角色

### 7.9 菜单管理 `/menus`

- 树形展示，节点上「加子项 / 编辑 / 删除」，删除无二次确认
- 改这里的菜单**不会**改变左侧导航（左侧是前端硬编码）

### 7.10 配置中心 `/config`

- 状态：`0 待审核 / 1 待执行 / 2 已驳回 / 3 已发布`
- 申请：`op_type` 1 新增 / 2 修改 / 3 删除；新增修改必须填内容；`.json` / `.yaml` 会校验格式
- 回滚：需填 Nacos 历史版本 `nid`
- 详情抽屉左右对比「Nacos 实时内容」与「申请内容」
- 复核：`action=1` 通过、`action=2` 驳回（驳回必须填意见）
- 执行：**唯一真正写 Nacos 的一步**
- 改/删不存在的配置 → `code=40400「配置不存在，无法修改/删除」`，不产生申请单

### 7.11 审计日志 `/audit`

- `GET /admin/audit/logs?tenant_id&limit`（limit 上限 1000，无 offset，分页在前端做）
- `id` 是 UUID 字符串；只有 `user_id`，没有用户名
- 结果列按成功/失败着色

### 7.12 会话运行 `/sessions`

- 仍是 `mock/tables.ts` 假数据，不发请求、刷新不变
- 后端只有单条查询，没有列表接口 → 判未实现，不用找 bug
