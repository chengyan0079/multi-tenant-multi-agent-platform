# 前端页面接口对接现状与测试清单

> 用途：按「前端有 UI + 后端有接口 + 端到端能跑通」三条件核对每个功能到底完成没有，供测试与排期使用。
> 代码基线：前端 `dashboard/src`，后端 `backend/api/v1`。

## 1. 完成判定标准

一项功能算「对接完成」必须同时满足三条，缺任意一条都记未完成：

| 条件 | 含义 |
| --- | --- |
| 后端接口已实现 | 路由存在、能返回正确数据、走统一 `{code,msg,data}` 信封 |
| 前端有入口并调真实接口 | 页面上有对应按钮/表单，Network 里能看到请求，不是 mock 数据 |
| 端到端验证过 | 真实点过一遍，成功路径与失败路径都有预期表现 |

判定结果只写事实，不写「大概能用」。因此下面分两种粒度：
**页面级**（这个页面整体算不算完成）和**功能点级**（具体哪一件事缺哪一侧）。

## 7. 页面测试要点

### 7.1 登录 `/login`

- 正常：提示「欢迎回来，xxx」→ 跳 `/dashboard`
- 密码错误：`401 + code=40100`，红色提示、不跳转
- 后端未启动：「网络异常，请确认后端服务已启动」
- 已登录访问 `/login` → 自动跳 `/dashboard`

### 7.2 监控概览 `/dashboard`

- 切 7/30 天重新请求；指标卡、趋势、占比、时段耗时、最近活动取接口数据
- 「刷新」带 `refresh=true`，跳过 60 秒 Redis 缓存
- 接口失败显示错误提示，不再回退示例数据
- 租户视角：智能体数按「全局启用且未被显式关闭」；成功率/占比在 `agent_run` 为空时用 API 日志兜底
- 超管可看租户用量排行（`tenant_ranking`）

### 7.3 智能体管理 `/agents/list`

- 列表含全局启停、新建/删除、模型绑定；开关调 `PATCH .../enabled`
- 租户开通策略 UI、Agent 详情仍未完成；租户策略可通过接口维护
- 注意：能力策略未配置视为开通，只有 `enabled=false` 才是关闭

### 7.4 工具与插件 `/tools`

- 列表、筛选、启停可用；没有调用次数统计（后端也没有）

### 7.5 模型注册表 `/models`

- 列表可按类型筛选；启用开关直接调 `PATCH .../status`
- **api_key**：后端脱敏返回 `***`，编辑弹窗留空表示保留原 key，前端不会把 `***` 写回
- 平台级资源，不分租户；改动即时影响运行时取模型

### 7.6 用户管理 `/users`

- 列表支持用户名、租户、创建时间筛选；详情抽屉改角色
- 无超管新建/删除用户、重置密码入口（后端也没有）

### 7.7 租户管理 `/tenants`

- 列表支持名称、创建时间筛选；新建租户会同时创建主租户管理员
- 抽屉：改名/启停、换管理员（新用户必须填密码）
- 删除租户已接；主租户/有业务数据时按后端错误提示处理

### 7.8 角色管理 `/roles`

- 详情抽屉的权限点是**覆盖保存**：勾选结果即全部权限点，取消勾选会删除
- 权限点选项来自后端 `/admin/rbac/scopes`，与 `Scope` 枚举对齐
- 内置角色不显示删除按钮；改内置角色权限会影响线上鉴权，测试用临时角色

### 7.9 菜单管理 `/menus`

- 树形展示，支持名称/路径/权限点模糊筛选、新建/编辑/删除
- 左侧导航已由登录响应 `menus` 驱动；改菜单/scope 后需重新登录生效

### 7.10 配置中心 `/config`

- 读取 Nacos 配置列表/分组/详情/历史
- 申请：新增/修改/删除；支持撤回自己的待复核申请
- 复核：通过即写 Nacos；驳回需填意见
- 详情抽屉左右对比「Nacos 实时内容」与「申请内容」
- 改/删不存在的配置会返回业务错误，不产生脏数据

### 7.11 审计 `/audit`

- 三个页面：业务审计 `/audit/operation`、登录日志 `/audit/login`、API 调用日志 `/audit/api`
- 业务审计：租户/操作人已 JOIN 名称；可按租户筛选
- 登录日志：租户名称、租户筛选
- API 日志：租户名称、调用域筛选（业务/管理/认证/看板）
- 注意：业务审计目前主要覆盖管理动作，QA/简历/文件等业务操作只进 API 调用日志

### 7.12 业务 Agent 页面

- QA `/agent/qa/*`：文件上传/批量上传/解析、流式问答（SSE）、停止生成、会话历史、结果/RAGAS
- 简历 `/agent/resume/analysis`：PDF 上传、列表轮询、报告详情、删除；旧 `/resume/*` 入口仍兼容
- 考试 `/agent/exam/*`：**前端仍是 mock**；后端提交/复核/确认接口已就绪，需先完成前端对接再端到端测试
